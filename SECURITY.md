# Security policy

## Supported versions

Only the [latest release](https://github.com/akshad-exe/CodeShredder/releases/latest) gets fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use
[private vulnerability reporting](https://github.com/akshad-exe/CodeShredder/security/advisories/new).

Include the version, your OS, steps to reproduce and the impact. This is a one-person project, so
replies are best effort.

In scope, for example: deleting paths outside what a scan returned, getting past the system-folder
or cache guards, running unintended commands, and problems with signed updates.

Ordinary cases where the app offers to delete the wrong thing belong in the
[safety issue form](https://github.com/akshad-exe/CodeShredder/issues/new?template=safety_issue.yml).

Builds are not code-signed yet; that is a known limitation. Verify downloads with the release checksums.
