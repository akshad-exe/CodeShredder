## The Problem

Every developer has folders they can't delete but dare not keep. A single `node_modules` can be 1.2 GB. A `target/` from one Rust build can be 8 GB. Six months of stale virtual environments, framework caches, and abandoned side-projects quietly eat a drive until builds start failing and laptops start thrashing.

Existing cleaners treat your disk like a storage closet. They show you a donut chart of "used space" and leave you to work out which of the 40,000 files is safe to remove. **That's backwards.** You don't want to know what's big — you already know a 9 GB `node_modules` is big. You want to know **which of these folders is junk, why it's junk, and whether it's safe to delete right now.**

## The Approach

CodeShredder scans folders you point it at and surfaces **only known-safe generated artifacts**, each one labelled with *why* it's removable and how much space it costs.

- **Trash-first, never silent.** Nothing is deleted permanently without explicit consent. Selected items go to the Recycle Bin / Trash so a wrong click is always recoverable.
- **Protects what matters.** Your `.git` directories, lockfiles, `.env` files, and source trees are never candidates — enforced in the safety layer, not in the UI.
- **Explains itself.** Every match carries a human-readable reason ("Rust build output, regenerated by `cargo build`").
- **Runs locally.** Zero telemetry. Nothing leaves your machine.

<td width="50%" valign="top">

**🔍 Shred**
Find heavy generated folders across your projects. Cache-aware rescans make repeat scans near-instant.

Clean package-manager and toolchain caches with dry-run preview before anything is removed.

Review and restore anything CodeShredder has cleaned, or purge permanently.

## 🚀 Quick Start

**Prerequisites:** [Rust](https://rustup.rs) (stable), [Bun](https://bun.sh), and the [Tauri v2 system dependencies](https://tauri.app/start/prerequisites/) for your platform.

```bash
git clone https://github.com/akshad-exe/CodeShredder.git
cd CodeShredder
bun install
bun run tauri:dev
```

That launches the desktop app with hot reload.

<details>
<summary><b>Other useful commands</b></summary>

```bash
# Frontend only, in a browser (no native shell)
bun run --filter codeshredder-frontend dev

# Production desktop bundle → src-tauri/target/release/bundle/
bun run tauri:build

# Marketing site → website/dist
cd website && bun install && bun run build

# Rust checks
cargo test  --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets
```
</details>

> **Linux build deps** — `sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev librsvg2-dev patchelf libayatana-appindicator3-dev`
>
> **WSL Optimizer** compiles only on Windows (`cfg(target_os = "windows")`), so WSL-specific changes need a Windows build to validate.

## 🏗️ Architecture

```
CodeShredder/
├── desktop/              React 19 + TypeScript frontend (Vite, Tailwind, shadcn/ui)
│   └── src/pages/        Overview · Shred · Caches · Wsl · LargeFiles · Duplicates · RecycleBin
├── src-tauri/            Rust backend (Tauri v2)
│   ├── src/commands/     #[tauri::command] IPC layer — thin, spawns blocking work
│   ├── src/services/     Business logic
│   │   ├── scanner/      discovery · measure · prune · roots · display
│   │   ├── caches.rs     cache specs, dry-run, size accounting
│   │   ├── explore.rs    large-file + video walks
│   │   ├── trash.rs      move-to-trash with restore
│   │   ├── safety.rs     protected-path rules
│   │   └── history.rs    cleanup history
│   ├── src/domain/       entry types + junk pattern definitions
│   └── src/storage/      persistence
└── website/              Marketing site (React + Tailwind v4)
```

**How a scan flows:**

1. A command handler validates the requested roots and spawns onto Tauri's blocking pool.
2. `scanner::walk_root` walks with `jwalk`, skipping `.git` and nested `node_modules` so one giant dependency tree doesn't hide its siblings.
3. Directory measurements run in parallel via `rayon`; a snapshot cache keyed on directory mtime makes repeat scans near-instant.
4. Matches stream to the UI over a channel as they're found, so the list fills progressively instead of blocking until the whole tree is walked.
5. `safety.rs` filters candidates against protected paths before anything can be selected.
6. Selected entries are moved to Trash — never hard-deleted.

**Key dependencies:** `tauri` 2 · `rayon` · `jwalk` · `trash` · `blake3` · `thiserror` · `tokio` · `serde` · `sysinfo`

## 🧪 Testing

```bash
cargo test --manifest-path src-tauri/Cargo.toml   # unit tests
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets
```

## 🛡️ Safety

CodeShredder deletes files. That's worth being explicit about:

- **Nothing is hard-deleted by default.** Items go to the system Trash/Recycle Bin and can be restored from the built-in Recycle Bin page.
- **Protected paths are enforced in the backend** — `.git`, lockfiles, `.env`, and source trees are filtered by `safety.rs` before any UI interaction, not merely hidden in the interface.
- **Nothing leaves your machine.** No telemetry, no accounts, no network calls.
- **Dry-run is available** for cache cleaning so you can see exactly what would go before committing.

If you find a case where CodeShredder offers to delete something it shouldn't, please [open a security issue](https://github.com/akshad-exe/CodeShredder/issues/new/choose) — that matters more than almost any other bug.
